# Y-Chat v0.3.5 — Standard Character Foundation

Diese Version baut bewusst **nur den Standard-Yōkai** sauber neu auf.

- eigener SVG-Character statt CSS-Kugel
- lebendige Augen + zufälliges Blickverhalten
- automatisches Blinzeln
- Bounce / Float Animation
- Mood-Gesichter: calm, happy, sleepy, sad, hyped, curious
- API im Browser: `Yokai.setMood('sad')`, `Yokai.blink()`, `Yokai.bounce()`, `Yokai.sleep()`, `Yokai.lookLeft()`, `Yokai.lookRight()`, `Yokai.lookCenter()`
- Klick/Tap auf den Yōkai löst Bounce aus
- andere Skins sind in dieser Foundation-Version absichtlich noch nicht aktivierbar; sie werden danach als eigene Character-Modelle gebaut.
