# Y-Chat v0.2 Demo

Render-ready Node/Socket.IO demo.

Features:
- Live chat only when both users are online
- 60-second disappearance after read
- Mobile reconnect + remembered Y-ID
- Yōkai swipe screen
- Kage animation
- XP / level / Y-Coins / simple mood logic

Not production-ready: no real E2E encryption, no payments, no moderation backend.
