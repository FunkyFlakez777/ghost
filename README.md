# Ghost Demo – Mac

## Start auf dem Mac
1. ZIP vollständig entpacken.
2. Doppelklick auf **Ghost starten.command**.
3. Falls macOS die Datei beim ersten Mal blockiert: **Rechtsklick → Öffnen → Öffnen**.
4. Falls Node.js fehlt, öffnet sich die offizielle Download-Seite. Dort die LTS-Version installieren und danach Ghost erneut starten.
5. Safari/der Standardbrowser öffnet Ghost automatisch.

Das Terminal-Fenster muss während des Tests offen bleiben.
